Neighborhood Safety Ranking App
Team Name: Software Engineering Group 2
Course: CS 3354.002 - Software Engineering

Project Description
Our project is a web application that helps people learn about neighborhood safety before moving to a new area. 
Users will be able to search for neighborhoods, view safety ratings, and submit their own ratings based on their experiences.

Project Objectives
Allow users to search for neighborhoods.
Display neighborhood safety ratings and reviews.
Allow registered users to submit ratings.
Provide an interactive map to locate neighborhoods.
Recommend neighborhoods based on available ratings.
Protect users' personal information.
